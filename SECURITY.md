# Security policy

## Supported version

Security fixes are applied to the current production version on the `main` branch. Older revisions are not maintained separately.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email `info@bright.supply` with:

- A concise description of the issue and its impact
- Steps or a minimal proof of concept that reproduce it
- The affected URL, browser, and operating system
- Any suggested mitigation, if known

Avoid including unrelated personal data or testing against other users. You may open a public issue for ordinary bugs that do not present a security or privacy risk.
